# Math. Comp. 稿件骨架

本文档是 `math-comp` 分支的可扩写稿件骨架。最终章节顺序、术语、claim
status 和 submission gates 仍以 [writing_guide.md](writing_guide.md) 为准；实验
执行状态只以 [exp_todo.md](exp_todo.md) 为准。这里不另建 TODO 清单，而是说明
每一节在什么证据条件下可以写成正式论文。

建议正文采用英文。本骨架用中文说明写作功能，并给出拟用英文标题、定义、
定理接口和图表位置。所有标为“候选”的结论在证明完成前不得改写为已证明
结果；所有性能结论在对应实验完成前必须保留条件语气。

## 0. Math. Comp. 范文给出的组织原则

由此采用以下总叙事：

1. 先定义一个真实的计算问题和统一成本模型；
2. 将 modular reduction 化为 nilpotent feedback inversion；
3. 证明 characteristic two 下的 sparse Frobenius factorization；
4. 给出正式算法以及 work--depth--space--setup 几何刻画；
5. 与 serial、specialized 和 multiplication-based 方法比较适用区域；
6. 用 matched microbenchmarks 和至少一个完整 computational-algebra workload
   检验理论后果；
7. 同时报告赢区、输区和模型失效处。

## 题名页

### Working title

> **Generalized Suwako: Sparse Modular Reduction with Logarithmic Feedback Depth**

题名中的 *feedback depth* 必须在第 2 节定义，不能让读者将其误解为 Boolean
gate depth、pipeline depth 或 wall-clock latency。

### Abstract：六句话骨架

摘要最后写，建议控制为一个自然段，并按以下依赖顺序展开：

1. **问题。** Binary polynomial modular reduction 是有限域算术、重复模平方、
   irreducibility testing 和 polynomial factorization 的基础步骤。
2. **已有方法的局限。** Sparse top-down folding 保留低 work，却可能形成长度由
   tap geometry 决定的 serial feedback chain；dense reciprocal/matrix 和
   multiplication-based reducers 采用不同的 setup、space 与 arithmetic tradeoff。
3. **方法。** 将 reduction 写成 truncated coefficient space 上的 nilpotent
   feedback equation，并以 characteristic-two Frobenius factors 应用其 reciprocal。
4. **已证明结果。** 仅在 Gate 2 完成后填写 correctness、精确 stage count、
   geometry-sensitive work、space 和 setup 的正式结论。
5. **已测结果。** 仅在 Gate 3 完成后填写平台、参数范围、matched baselines、
   winning/losing regions；不得只报最佳 speedup。
6. **计算后果。** 仅在 Gate 4 完成后填写 repeated modular squaring、
   irreducibility testing 或 factorization 的端到端结果，并明确适用边界。

禁止在摘要中先行使用 `first`、`optimal`、`practical`、`constant-time` 或
`significant`。若最终 workload 没有端到端收益，摘要应将贡献限定为新算法和
精确 tradeoff characterization。

## 1. Introduction

目标篇幅：约 3--4 页。前两页不使用 \(U,V,L,H\) 等内部符号。

### 1.1 Computational setting

- 从 \(\mathbb F_2[x]\) 中的 modular reduction 进入问题；
- 说明 reduction 在 multiplication、squaring、Frobenius iteration、
  factorization 和 irreducibility testing 中的位置；
- 区分“适用于任意 monic binary modulus”和“在 sparse modulus 上 work 有利”。

### 1.2 The missing tradeoff

- serial sparse folding：setup 小、support-sensitive，但反馈链可能很长；
- fixed unrolled reducers：对固定低权模数很强，但不是 uniform arbitrary-modulus
  baseline；
- Barrett/Montgomery：适合较稠密区域，但使用 multiplication kernels 和
  modulus-dependent data；
- reciprocal/Toeplitz/dense linear map：可并行，却可能 materialize dense
  intermediate structure；
- 提出准确问题：能否在不展开 dense reciprocal/reduction matrix 的前提下，
  保留原始 tap support，并缩短 sequential feedback chain？

### 1.3 Main idea

只给一张高层图和一段直觉：

$$
\text{modular reduction}
\longrightarrow
H=(I+U)Y
\longrightarrow
(I+U)^{-1}=\prod_k(I+U^{2^k})
\longrightarrow
\text{sparse shift/XOR stages}.
$$

解释 doubling 的作用，但不要在这里展开证明。强调 cross terms 通过 stages 的
composition 隐式出现，而非被错误地宣称为“reciprocal 本身始终稀疏”。

### 1.4 Contributions

最终应成为四至五条平行、可核查的贡献；目前按证据等级保留以下接口：

1. **Algebraic formulation（候选证明）。** 对任意 monic binary modulus，把
   degree-below-\(2m\) reduction 化为 truncated-space nilpotent feedback inverse。
2. **Sparse factorization（候选证明）。** 在 characteristic two 下，用 Frobenius
   powers 给出不产生 per-stage combinatorial support growth 的 factored inverse。
3. **Geometry theorem（候选证明）。** 给出精确 feedback-stage count 和
   scheduled active-tap work，并由完整 tap geometry 推出 work--depth--space--setup
   bounds。
4. **Implementation/evaluation（待测）。** 在统一 API 和输入合同下比较 serial、
   specialized sparse、generalized Suwako、Barrett/Montgomery 与 generic/dense
   baselines，形成包含负结果的 phase diagram。
5. **Computational consequence（待测）。** 在 repeated modular squaring 与一个
   irreducibility/factorization workload 中验证 reduction 结果是否转化为端到端收益。

若第 5 条没有通过 Gate 4，应删除该贡献条目，而不是用 reduction-only 数据替代。

### 1.5 Scope and limitations

在 introduction 主动声明：

- 不是新的 reciprocal identity；
- 不是所有 moduli 上都比 Barrett/Montgomery 快；
- feedback depth 不等于 bounded-fan-in gate depth；
- 不声称完整 field multiplication 获得无条件渐近改进；
- irreducibility 不是 correctness 的假设，只是 field application 的需要；
- cryptographic protocol、Koblitz 和 reversible circuits 不属于本分支贡献。

### 1.6 Organization

用一段话依次说明 Sections 2--10；避免逐小节罗列。

## 2. Preliminaries and Cost Models

目标：读者在进入算法前已经知道输入、输出、支持集合和每一种 cost 的含义。

### 2.1 Binary polynomials and truncated spaces

定义 coefficient-vector convention、degree bound、shift direction、top-word masking，
以及长度 \(m\) 的 truncated space。

### 2.2 Sparse monic moduli

固定全文记号：

$$
g(x)=x^m+q(x)=x^m+\bigoplus_{t\in T}x^t,
\qquad
\Delta_t=m-t,
$$

$$
h=1+|T|,
\qquad
\Delta_{\min}=\min_{t\in T}\Delta_t
$$

其中 \(q=0\) 单独处理。明确 constant tap 对 final low assembly 和 feedback 的不同
作用。

### 2.3 Reduction contract

输入 \(A\) 满足 \(\deg A<2m\)，输出是唯一 \(R\) 满足
\(A\equiv R\pmod g\) 且 \(\deg R<m\)。说明 monicity 足以保证 remainder 唯一；
irreducibility 不需要出现于 correctness theorem。

### 2.4 Cost models

分别定义且不混用：

- coefficient work；
- word work；
- feedback depth；
- bounded-fan-in algebraic depth（若保留）；
- setup time and storage；
- temporary space；
- machine latency and throughput。

给出一张“符号—单位—是否理论/实测”的表。主定理中的 \(W_{\rm fb}\) 必须明确是
scheduled coefficient-operation count，而不是 instruction count 或 minimal XOR count。

## 3. Existing Reduction Paradigms

本节是问题建模，不替代第 7 节的完整 related work。

### 3.1 Serial sparse folding

给出统一 contract 下的伪代码、work 和 chain-length 参数。解释为什么 tap weight
不足以描述 feedback difficulty。

### 3.2 Fixed-modulus sparse reduction

涵盖 trinomials、pentanomials、Lopez--Dahab 和 generated unrolled code。说明其
fixed-family/fixed-modulus 优势以及作为 strongest baseline 的必要性。

### 3.3 Dense linear maps and generic division

说明矩阵或通用 polynomial remainder 的 setup、storage 和通用性。

### 3.4 Barrett and Montgomery reduction

固定 reciprocal/inverse、partial products、representation 和 amortization 的比较
口径，避免用 shift/XOR operation count 直接推出 wall-clock 胜负。

### 3.5 Comparison table

表 1 至少包含：applicability、steady-state work model、feedback/dependency depth、
setup、stored modulus data、是否 specialized、主要优势与主要失效区。

## 4. Sparse Feedback Operators

这是第一段正式理论。证明顺序不可被实现细节打断。

### 4.1 Low/high decomposition

写

$$
A=L+x^mH,
\qquad
qY=S(Y)+x^mU(Y).
$$

**Lemma 1（one-step decomposition，候选）。** 展开 \(A-gY\)，明确 low/high
parts。

### 4.2 Feedback recurrence

**Lemma 2（reduction recurrence，候选）。** 证明求解

$$
H=(I+U)Y
$$

后，remainder 为 \(L+S(Y)\)。将 odd-characteristic 的符号差异留到附录。

### 4.3 Shift representation and nilpotency

以 truncated right-shift \(N\) 写

$$
U=\sum_{t\in T_+}N^{\Delta_t}.
$$

**Lemma 3（nilpotency，候选）。** 给出 \(U^{2^r}=0\) 所需的 sharp stage bound，
并单独处理 \(U=0\)。

### 4.4 Sparse Frobenius powers

**Lemma 4（Frobenius sparsity，候选）。** 在 binary scalar setting 中证明

$$
U^{2^k}=\sum_{t\in T_+}N^{2^k\Delta_t}.
$$

一般 coefficient algebra 版本需区分 formal scheduled support 与 actual nonzero
support；正文可只陈述 binary 版本，将 reduced/non-reduced 的量词放入附录。

### 4.5 Factored truncated reciprocal

**Theorem 1（sparse inverse factorization，候选）。** 证明

$$
(I+U)^{-1}
=\prod_{k=0}^{r-1}(I+U^{2^k}),
\qquad
r=\left\lceil\log_2\frac m{\Delta_{\min}}\right\rceil.
$$

随后解释它与 truncated reciprocal、finite geometric inverse 和
Newton/Hensel-style precision doubling 的关系；经典 identity 与本文 specialization
必须分开陈述。

## 5. Generalized Suwako Reduction

### 5.1 Algorithm 1: schedule construction

输入为 \((m,T)\)，输出每个 stage 的 active shifts 以及 final low-assembly taps。
明确 schedule 是 modulus-public setup，不接触 field-element secrets。

### 5.2 Algorithm 2: reduction

伪代码必须显式使用 synchronous stage update：每个 stage 的所有 taps 读取同一个
immutable old state，写入新 state。随后执行 final low-part assembly 和 top-word
mask。

### 5.3 Correctness

**Theorem 2（algorithmic correctness，候选）。** 对任意 monic binary modulus 和
任意 \(\deg A<2m\) 的输入，Algorithm 2 输出 \(A\bmod g\)。证明只引用 Lemmas
1--4 和 Theorem 1，不引用测试结果。

### 5.4 Worked examples

至少两个例子：

- 一个 trinomial，展示单 tap 的 doubling shifts；
- 一个 multi-tap/high-tap modulus，展示 stage composition 如何隐式生成 mixed
  feedback paths。

例子应包含 \(T\)、\(\Delta_t\)、每层 active taps 和最终 assembly，但不要用友好
例子代替一般证明。

### 5.5 Edge cases

覆盖 \(q=0\)、constant-only \(q\)、constant-free modulus、reducible modulus、dense
support 与 non-word-aligned \(m\)。constant-time 只能描述 public fixed schedule 下的
控制流性质，不在此作完整侧信道声明。

## 6. Work--Depth--Space Geometry

### 6.1 Exact feedback depth

**Theorem 3（feedback depth，候选）。** 给出精确 stage count

$$
r=\left\lceil\log_2\frac m{\Delta_{\min}}\right\rceil,
$$

并解释它衡量 sequential feedback factors，而非 gate depth。

### 6.2 Exact scheduled work

**Theorem 4（active-tap work，候选）。** 定义

$$
h_k=\#\{t:2^k\Delta_t<m\}
$$

并证明

$$
W_{\rm fb}
=\sum_{t}\sum_{k\ge0}[m-2^k\Delta_t]_+.
$$

给出 full tap geometry 为什么比 \((h,\Delta_{\min})\) 更精确，并推导

$$
W_{\rm fb}
<m\sum_t\left\lceil\log_2\frac m{\Delta_t}\right\rceil
=O\!\left(mh\left(1+\log\frac mh\right)\right).
$$

### 6.3 Space and setup

**Theorem 5（space/setup，候选）。** 分开报告 working buffers、active schedule
storage、generated-code size 和 one-time setup work；不要只写大 \(O\) 而隐藏常数
与 modulus dependence。

### 6.4 Family corollaries

按证明成熟度选择：constant-weight families、fixed \(\Delta_{\min}\)、random fixed-
weight supports、schoolbook multiplication comparison。Karatsuba 或 quasi-linear
multiplication comparison只有在口径完整时保留。

### 6.5 Depth-model boundary and optional lower bound

若 generic-coefficient bounded-fan-in lower bound 完成，则以独立 theorem 陈述其
coefficient domain、fan-in、fanout/dependency assumptions。否则只作为 open problem，
不得由 feedback-stage count 推出普遍 gate lower bound。

### 6.6 Analytical comparison

用一张 theorem-summary table 汇总 serial、GS 和 multiplication-based 方法中真正
可比较的量。明确理论只预测候选 region，机器 crossover 必须由第 9 节测量。

## 7. Prior Art and Novelty Boundary

本节由 [sections/related_work.md](sections/related_work.md) 压缩而来，建议按“最近的
机制”而不是按年代组织：

1. polynomial division、triangular Toeplitz inversion 与 truncated reciprocals；
2. formal-series inversion、finite geometric inverse 与 Newton/Hensel doubling；
3. LFSR look-ahead、parallel recurrence 与 CRC unfolding；
4. sparse finite-field reduction 和 specialized trinomial/pentanomial methods；
5. Barrett/Montgomery 与 precomputation-free restricted families；
6. dense linear-map/XOR-network synthesis。

每一组都回答三个问题：已知什么、与本文共享什么、本文还必须证明或测量什么。
结尾使用 `writing_guide.md` 中已关闭 hostile audit 后的精确组合边界，不声称
Frobenius identity、reciprocal inversion 或一般 parallel division 本身新颖。

## 8. Implementations and Validation

### 8.1 Reference and falsification suites

描述独立 oracle 路径以及 GF(2)、GF(4)、dual numbers、support geometry 和
\(\mathbb F_3\) 的测试域。数十万 exhaustive/random cases 是 computational
falsification，不是 theorem proof。详细 seeds、case counts 和方法放附录。

### 8.2 Unified native API

说明 generalized Suwako、serial、naive 和 gf2x-backed Barrett 的统一输入输出
contract，以及 shared primitive 只用于消除不公平的底层 shift 实现差异。

### 8.3 Portable and specialized implementations

依次说明 portable scalar C、fixed-modulus generated code、strong specialized
trinomial/pentanomial reducers，以及最终实际完成的 SIMD 实现。未完成的实现不在
正文占位。

### 8.4 Reproducibility contract

记录 compiler、flags、machine、affinity/frequency policy、gf2x path、seed、tap
manifest、input distribution、timed boundary、setup policy 与 repetitions。正文给
摘要，完整命令和 manifests 放 artifact/appendix。

## 9. Evaluation and Computational Consequences

本节必须模仿 Math. Comp. 范文把 theory-versus-practice 和 application result 分开，
不能只堆 benchmark 表。

### 9.1 Experimental questions and platforms

从现有 RQ1--RQ7 中压缩为四个正文问题：

1. stage/work prediction 是否与 instrumentation 一致；
2. 哪些 \((m,h,\Delta_{\min},\{\Delta_t\})\) 区域由 GS、serial 或 Barrett 获胜；
3. setup amortization 和 machine-word effects 如何改变边界；
4. reduction-level 差异是否进入 repeated-squaring 与完整 algebra workload。

### 9.2 Cost-model validation

先比较 predicted stage count、active-tap work、word shifts 与实测 counters/runtime。
像 von zur Gathen--Gerhard 一样报告 theory/practice correlation，同时列出 memory
traffic、stage barriers 或 alignment 导致的偏离。

### 9.3 Reduction phase diagram

固定 \(m\) 分 panel：横轴为 modulus Hamming weight \(h\)，纵轴为
\(m/\Delta_{\min}\) 的 base-two logarithmic scale，点颜色表示 matched winner。
报告 median/p90/p99、uncertain cells、friendly regions 和 hostile regions。

### 9.4 Work--depth--setup tradeoff

分别展示：

- stage count versus \(\Delta_{\min}\)；
- predicted active-tap work versus runtime；
- fixed-gap weight sweep 与 fixed-weight gap sweep；
- setup amortization over \(K\)；
- Pareto map，而非单一“最快”排序。

### 9.5 Repeated modular squaring

分开测 square formation、reduction 和 complete modular square。输入必须是真实
square-shaped state 或 application-generated Frobenius chain，不能用 high monomial
微基准替代。比较 strongest general 和 applicable specialized squarers。

### 9.6 End-to-end workload

优先选择 Rabin irreducibility test、distinct-degree factorization kernel、primitive-
polynomial certification 或 sparse-polynomial search 中至少一个。报告各阶段时间占比、
early exits、candidate distribution 和 losing cases。

只有本小节完成，Introduction/Abstract 才能写“computational consequence”。若结果
为负，应诚实说明 reduction improvement 被 squaring formation、GCD 或 specialized
formula 吞没。

### 9.7 Modulus-selection consequence

若实验表明不同 reducer 选择出不同 platform-optimal irreducible modulus，则作为
第二 application result；否则将其报告为边界结论。必须固定 optimization objective，
不能在 reduction、squaring 和 total arithmetic 之间事后切换指标。

### 9.8 Negative results and threats to validity

明确列出 dense/high-weight、small-degree、friendly low-tap、expensive cross-word shift、
specialized formula 和 quasi-linear multiplication 占优的区域。讨论 compiler、machine、
input distribution、public-modulus setup 与 sample size 对外推性的限制。

## 10. Consequences, Limitations, and Conclusion

### 10.1 What the result changes

根据最终证据选择一至两个结论：

- tap geometry 而非 Hamming weight alone 决定 sparse feedback difficulty；
- factored reciprocal 提供一种不 materialize dense reciprocal 的不同
  work--depth--setup tradeoff；
- reducer-aware modulus selection 是否改变可取的 sparse modulus region；
- repeated Frobenius workload 中 reduction 是否真正成为可利用的收益。

### 10.2 What it does not change

重申 dense moduli、specialized fixed moduli、complete multiplication、gate depth、
constant-time 和跨平台可迁移性方面的限制。coefficient algebras 与 positive
characteristic 仅在附录给出，不扩张主叙事。

### 10.3 Conclusion

用一个短段依次回收：问题、operator formulation、Frobenius factorization、精确
geometry、实测适用区间和 application consequence。最后一句可沿用当前概念而重新
措辞：characteristic-two structure 能在不先稠密化原反馈算子的情况下缩短反馈链。

不要在 conclusion 引入新定理、新 baseline 或未在第 9 节出现的性能数字。
